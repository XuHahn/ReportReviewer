# 示例与回归数据说明

`example/` 存放本地演示、真实回归和人工核对资料。目录包含客户文档或大文件，默认不提交 Git；只有本说明文件纳入版本管理。

## 数据集

| 路径 | 用途 | 状态 |
|---|---|---|
| `E20260402869601*` | 完整四文档回归基线 | 真实调试数据 |
| `test_set_01/` | 由脚本生成的含错/无错演示集 | 合成数据 |
| `test_set_02/` | 非固定 Excel DVP 模板兼容性 | 真实模板回归 |
| `test_set_03/` | 灯具试验计划与 Word 报告兼容性 | 高置信度套件副本 |
| `HC_E202605287495/` | 四文档加 ISO 7637-2 标准 | 标准知识库与原始记录回归基线 |
| `report/` | 多厂商 Word 报告集合 | 报告抽取扩展样本 |
| `set01/` | 其他在标注资料 | 非高置信度，不作为准确率结论 |

## 推荐前端回归流程

1. 执行项目根目录 `./start.sh`。
2. 在“上传审核”中新建文档集。
3. 上传四份必需资料；需要标准审查时，从标准库选择已发布标准。
4. 逐份打开“核查”，确认提取对象数量、字段值和原文证据。
5. 锁定并提交审核，检查问题是否重复、每条是否能回指证据。
6. 创建修订，替换一份文件并重新审核，确认上一轮结果在新结果完成前仍可查看。
7. 导出 Excel，核对序号、级别、问题类别、问题描述和来源证据。

## 自动化测试

普通测试不调用线上模型：

```bash
cd backend && pytest -q tests/
```

高置信度语料测试需显式开启，具体开关见 `backend/tests/test_online_cases_corpus.py`。运行真实 API 前确认费用、模型和日志脱敏设置。

## 合成数据

`generate_test_set.py` 可重建 `test_set_01/`：

```bash
python example/generate_test_set.py --errors
python example/generate_test_set.py --clean
```

合成数据只能验证已知规则，不能替代真实厂商模板的误报/漏报评估。准确率结论必须基于人工标注真值。
