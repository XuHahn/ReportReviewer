# EMC 审核台 Shadow UX

这是独立于正式前端的可操作影子版本，所有数据均为演示状态，不会写入后端。

启动：

```bash
python3 -m http.server 4174 --directory design/shadow-review
```

打开 <http://127.0.0.1:4174/>。

支持流程：上传映射、提取核查、标准与锁定、审核执行、问题核查、版本历史与 ZIP 成员清单。问题页可切换结果冲突、项目覆盖、规格结果、身份确认和已闭环五种展示方式；提取页可打开原文大图、点击证据编号聚焦红框、双击图片放大，并显示角标页码与实际页码说明。

影子运行时会把文件元数据、锁定状态、审核进度和人工处理结果保存到浏览器 `localStorage`，因此刷新页面不会丢失流程。若后端 `8000` 端口可用，顶部会显示后端连接状态；后端不可用时仍可完整体验本地工作流，不会伪装成已完成真实审核。
