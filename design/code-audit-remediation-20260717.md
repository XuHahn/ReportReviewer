# 全代码审计整改（2026-07-17）

状态：历史记录，已由 2026-07-28 统一证据图重构取代。

## 整改范围

- 文档集管理：后台解锁统一进入 `revision`，增加管理员删除 API，并在事务内清理文档、提取结果、问题、指标、标准选择和集合级映射。
- 权限边界：审计日志仅管理员可读；项目组按成员可见，仅创建者或管理员可维护；文档集只能绑定用户所属项目组。
- 标准治理：标准写操作统一为管理员或标准审核员；已有发布版本或审核引用时禁止物理删除并返回 409。
- 数据口径：非管理员统计仅包含本人文档集；无严重问题率只统计已经完成审核的文档集；问题总数包含严重、警告和提示。
- 运行可靠性：SSE 同时以 `complete` 和 `error` 结束并保留终态供晚订阅者读取；标准知识与图谱任务纳入应用任务注册表，服务关闭时统一取消。
- 动态配置：上传限制、批量导出数、限流和 DeepSeek API 地址在运行时读取；管理端保存前执行白名单、范围和 HTTPS 校验。
- 前端与后台：移除不参与当前管线的自定义规则入口和旧报告管理页；统计、报告列表、问题页全部切换到文档集管线；页面按需加载。
- 依赖与启动：PDF 读取迁移到 `pypdf`；数据库初始化统一到 FastAPI lifespan，移除重复 startup 迁移。

## 后续状态

2026-07-28 重构已删除旧报告、审核规则和旧问题表，不再保留兼容 API。正式业务入口为 `/api/sets`、`/api/sets/{set_id}/review-runs` 和人工发布的标准版本。
